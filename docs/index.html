// FEATURES

Everything you need.
Nothing you don't.

A complete private PaaS stack built for engineers who want Vercel-grade UX without the vendor lock-in.

🌐
Web Control Plane
Vercel/Railway-aesthetic dashboard at localhost:8080. Real-time SVG topology graph, cgroups telemetry, live container logs, and interactive SSH terminal — all in one place.
⌘K Spotlight Palette
🗄️
1-Click Databases
Instant provisioning for PostgreSQL, MongoDB, MySQL, Redis, and MinIO S3. Databases run strictly inside Swarm overlay networks — unreachable from the public internet.
Recovery Mode Included
🚀
Zero-Downtime Deploys
Automated Traefik v3 HTTPS SSL via Let's Encrypt. Docker Swarm start-first rolling updates with automatic rollback on deployment failures.
Auto-rollback on failure
🔑
SSH Key Access Control
Real-time team key management. Add and revoke developer SSH access instantly, with Vultr Master Account Protection to prevent accidental deletion of primary server credentials.
Master Key Protected
🏗️
Multi-Node Cluster Scaling
Automated Terraform provisioning of dedicated worker nodes via Vultr API v2 across regions — defaulted to Mexico City (mex). Scale horizontally in minutes.
Vultr API v2 · Terraform
📦
Custom S3 Backup Exporter
Stream backups directly to MinIO S3, Cloudflare R2, AWS S3, DigitalOcean Spaces, or Wasabi. Or keep them local at /opt/tarhiata/backups.
Multi-provider S3
📜
Immutable Audit Logger
NDJSON audit trail tracking every deployment, link, node provisioning, and configuration event. Full security and compliance history on your own disk.
NDJSON · Immutable
🔗
Service Linking Engine
Connect two services and auto-inject the target connection URI into environment variables. Link a Node.js API to PostgreSQL with a single command — no manual DNS config.
Auto ENV injection
🌍
Multi-PC State Sync
Infrastructure topology is exported as non-sensitive state references at /opt/tarhiata/state.json. Connecting from a new PC automatically imports the entire cluster state instantly.
Local-First · Stateless
